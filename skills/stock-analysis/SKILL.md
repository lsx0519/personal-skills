# Stock Analysis Skill

## 1. 核心工作流

面对一只股票，按以下顺序处理：

1. **确认数据**
   - 明确交易日期、时间点、周期。
   - 区分日线收盘数据与盘中数据。
   - 当前数据不足时明确说明，不猜测。

2. **描述市场结构**
   - 当前价格相对近期高低点的位置。
   - 识别阶段性支撑、阻力、前高、前低。
   - 判断趋势是反弹、震荡还是趋势延续，避免仅凭单根 K 线下结论。

3. **观察量价关系**
   - 上涨是否伴随成交量放大。
   - 下跌是否放量。
   - 突破是否有量能确认。
   - 单独的主力资金净流入/流出不得作为买卖依据。

4. **区分信号强弱**
   - 支撑测试 ≠ 底部确认。
   - 反弹 ≠ 趋势反转。
   - 局部阻力突破 ≠ 日线级别结构突破。
   - 大涨日 ≠ 应立即追涨。

5. **执行规则**
   - 优先考虑右侧确认。
   - 补仓必须有独立的触发条件，不能因为“成本高/跌得多”而补仓。
   - 已有较大底仓时，将底仓与交易仓分开管理。
   - 新增仓位必须预先定义失败条件。

6. **复盘/回测**
   - 先固定规则，再查看历史结果。
   - 禁止未来函数和 look-ahead bias。
   - 明确样本数量、交易成本、数据缺口和参数敏感性。
   - 样本过少时，只能称为候选框架，不能称为稳定策略。

## 2. 当前采用的候选右侧规则

这是研究框架，不是经过充分验证的盈利策略。

### 支撑测试

满足以下条件时记录候选支撑测试：

- 当日最低价 <= 前 5 个交易日最低价 × 1.02
- 当日收盘价 >= 当日开盘价

### 支撑确认

观察后续 3 个交易日：

- 后续 3 日不收盘跌破该支撑测试低点。

### 阻力与突破

以支撑测试及确认窗口形成的近期高点作为候选阻力。

未来最多 5 个交易日内，同时满足：

- 收盘价 > 候选阻力 × 1.005
- 成交量 >= 前 5 日平均成交量 × 1.3
- 当日涨幅 <= 5.5%

才记录为正式右侧入场信号。

### 退出

入场后：

- 若收盘价 < 前一交易日最低价，则退出交易仓。
- 否则最多持有 5 个交易日。

## 3. 仓位管理

建议把持仓逻辑拆成：

- **底仓**：用于长期/中期跟踪，不因单日波动频繁调整。
- **交易仓**：只有正式信号出现才增减。

对于已经较重的仓位：

- 不因为“价格低于成本”自动补仓。
- 不因为盘中突破局部阻力就追涨。
- 正式信号出现后也要考虑总仓位上限。
- 突破失败时，优先处理新增交易仓，而不是把所有仓位一并机械卖出。

## 4. 盘中分析与正式信号必须分离

盘中可以描述：

- 当前价格
- 分时高低点
- 买卖盘
- 量能变化
- 局部阻力突破

但盘中判断不能直接改写日线规则。

例如：盘中突破 14.30/14.50，只能说明局部结构改善；如果更高一级的日线结构高点仍未突破，就不能直接称为“正式突破”。

## 5. 反向验证

每次形成一个交易判断，都尽量做：

- 最近若干交易日回看
- 历史盲测
- 参数敏感性检查
- 失败案例复盘

目标不是证明“预测准确”，而是检查规则是否自洽、是否容易产生事后解释。

## 6. 表达规范

回答交易问题时：

- 先给结论，再给关键依据。
- 给出明确价格/结构条件，而不是只说“观察”。
- 把“事实”和“推断”分开。
- 对不确定数据明确标注。
- 不用单一指标解释复杂走势。
