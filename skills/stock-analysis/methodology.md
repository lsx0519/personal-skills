# Stock Analysis Methodology

## A. 价格结构

优先观察：

- 前期低点是否被有效跌破
- 前期高点是否被有效突破
- 突破后是否能够站稳
- 当前价格是否处于前高/前低之间的中间区域

“支撑”是一个区域/假设，不是精确到一分钱的绝对价格。

## B. 成交量

量价判断遵循：

- 放量上涨：说明上涨参与度提高，但不自动意味着继续上涨。
- 缩量回调：卖压可能减弱，但不自动意味着见底。
- 放量下跌：风险权重提高。
- 放量突破：比无量突破更值得关注，但仍需要观察突破是否失败。

## C. 资金流

主力资金、超大单等指标容易受口径和统计方法影响，只作为辅助信息。

不能使用：

> “主力净流入，所以必涨”

这类单指标因果推断。

## D. 右侧确认

一个较完整的右侧信号至少包含：

**支撑测试 → 支撑保持 → 阻力形成 → 阻力突破 → 成交量确认**

其中任一环节缺失，都应降低信号强度。

## E. 风险控制

交易前明确：

- 入场条件
- 最大新增仓位
- 失败条件
- 退出条件
- 最大持有周期

这样可以避免因为持仓成本而不断修改规则。

## F. 回测纪律

回测前冻结：

- 信号定义
- 参数
- 入场价格
- 退出规则
- 数据范围

回测后报告：

- 样本数
- 胜率
- 平均收益
- 最大回撤（如可计算）
- 单笔极端收益对整体结果的影响
- 参数变化后的稳定性

如果只有少量信号，即使历史结果很好，也只能作为研究线索。
